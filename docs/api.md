# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 示例字段说明

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `items` | 数组 | 示例中的文档条目集合 |
| `items[].id` | 整数 | 单个文档条目的标识，例如 `1` |
| `items[].title` | 字符串 | 单个文档的标题，例如“使用指南” |

在上面的 JSON 中，`items` 包含一个文档条目，其标题对应本站的[使用指南](guide.md)。这段示例用来说明如何在 Markdown 中展示接口方法、路径、结构化返回值和字段含义。

## 示例的阅读与使用

阅读接口文档时，可以先确认请求方法和路径，再对照返回示例理解每个字段。这里的 `/api/docs` 只是演示路径；本项目是静态文档网站，没有实现该接口，也没有提供可直接调用的后端服务。

本页展示的 JSON 可以作为接口文档排版的参考。若未来接入真实服务，还需要根据实际实现补充服务地址、请求参数、状态码、错误返回以及是否需要身份认证等信息，不能将这些示例字段当作已经上线的服务约定。

## 与本次实践的关系

本次项目的目标是练习文档构建与发布。本页通过代码块和字段表格展示技术文档中常见的内容形式，方便在预览时检查代码缩进、表格渲染和页面链接是否正常。
