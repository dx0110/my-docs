# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 我的介绍与实践动机

我是 dx0110，我的 [GitHub 个人主页](https://github.com/dx0110)用于展示我的公开项目。这次创建个人文档网站，主要是为了练习通过 GitHub Actions 自动部署静态文档到 GitHub Pages。
