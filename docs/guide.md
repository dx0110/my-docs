# 使用指南

1. 修改 docs 目录中的 Markdown 文件。
2. 在本地预览并检查页面及链接。
3. 提交修改并推送到 main 分支。
4. 在 Actions 页面查看构建与部署状态。
5. 打开网站检查内容是否更新。

## 常用命令

- python -m mkdocs serve：本地预览。
- python -m mkdocs build --strict：构建网站并严格检查警告。

## 本地操作示例

以下命令在项目根目录执行，前提是当前 Python 环境已经安装 MkDocs，以及站点配置中使用的主题和插件，并且已经填写好 `mkdocs.yml`。

```powershell
# 启动本地预览，打开终端中显示的网站地址
python -m mkdocs serve

# 预览结束后按 Ctrl+C 停止服务，再执行严格构建
python -m mkdocs build --strict
```

预览时应逐页检查标题、正文、表格和代码块的显示效果，并点击页面中的链接，确认能够进入目标页面。严格构建可以辅助检查构建警告，但仍需要人工确认内容是否完整、外部链接是否可访问。

## 更新与发布检查

| 阶段 | 要检查的内容 | 完成标准 |
| --- | --- | --- |
| 修改文档 | Markdown 文件是否保存 | 本地预览能看到本次新增内容 |
| 检查链接 | 首页、指南、API、关于页面之间的链接 | 点击后进入预期页面 |
| 本地构建 | 严格构建命令的执行结果 | 命令成功结束，无待处理的警告 |
| 自动部署 | 推送后对应的 Actions 运行记录 | 构建与部署步骤均成功 |
| 线上验收 | Pages 网站实际展示的内容 | 能看到本次更新且页面可正常跳转 |

上述自动部署流程依赖正确的工作流和仓库 Pages 设置；提交文档后，应以实际运行记录和线上页面作为发布结果的依据。
