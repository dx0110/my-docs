## 我的项目介绍

我创建这个项目，是为了练习通过 GitHub Actions 将静态文档自动部署到 GitHub Pages。目前我已经完成了个人网页的构建，希望通过这次实践了解文档编写与自动发布之间的联系。

这个网站既是我的个人文档入口，也是记录本次实践的地方。在保留已有内容的基础上继续补充说明，让页面除了展示效果之外，也能帮助自己回顾操作步骤。
